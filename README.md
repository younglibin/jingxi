## 当前设计方向

首页采用纵向长页滚动，包含 9 个内容区块，配合首屏卡片展开、滚动显现和局部横向画廊。访客自主控制浏览节奏，整页不定时自动轮播，不强制每次翻一屏。作品点击后进入独立详情页。

作品图片、品牌文字和公司信息由维护者提供，当前设计允许使用可替换占位。公开网站供访客浏览，管理后台供维护者上传作品和维护内容。
