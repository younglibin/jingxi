记录本会话截至 2026-10-26 的设计方案与已完成修订，作为仓库中的设计评审入口。设计仍使用占位作品和品牌内容；本次归档不表示已经通过最终评审或完成网站开发。

## 首页的浏览方式

首页是一张可纵向滚动的长网页。Figma 将整页画成一张长画板，是为了展示各区块顺序和完整布局；实际浏览器只显示当前视口，访客向下滚动继续阅读。

首页采用长页滚动配合局部动效：进入时首屏卡片展开，区块进入视口时文字或作品逐步出现，画廊可局部横向浏览并暂停。整页不按计时器轮播，也不强制整屏翻页；点击作品进入独立详情。连续滚动与动画联动仍需在后续开发中实现和验证。

| 区块 | 功能作用 |
| --- | --- |
| H01 首屏作品展开 | 介绍品牌，展示作品印象，提供浏览作品入口 |
| H02 阶梯式精选作品 | 突出代表项目，进入详情或全部作品 |
| H03 品牌视觉与合作标志 | 呈现品牌横幅和合作信息 |
| H04 品牌主张 | 在作品之间解释品牌定位，支持逐句强调 |
| H05 文件夹式作品分类 | 切换分类预览，进入相应作品列表 |
| H06 双排作品画廊 | 局部横向浏览作品，支持暂停 |
| H07 案例故事 | 引导阅读具体案例 |
| H08 服务或能力 | 介绍可提供的能力 |
| H09 联系收尾 | 提供联系入口和结束视觉 |

G01 导航与页脚、G02 作品卡片与放大层由页面复用。各区块的内容来源、空状态和验收条件见 [模块需求说明](requirements/module-requirements-v0.2.md)。

## 编号含义

| 标记 | 含义 | 阅读方式 |
| --- | --- | --- |
| P01 至 P04 | 公开页面模板编号 | P01 是首页，P03 是详情页 |
| H01 至 H09 | 首页内部区块编号 | 位于同一长网页的不同位置 |
| G | 全站复用模块 | 例如导航页脚和作品卡片 |
| A | 管理相关模块 | 需求文档与画板可能标到不同粒度，以中文名称对应 |
| S | 补充状态 | 例如空结果、弹窗或失败状态 |
| R | 响应式样例 | 例如 320 和 768 宽度 |
| D1.1 | 交付标注修订编号 | 用于识别尺寸和交付说明，不能当作页面路由 |
| V1.1 | 整体设计修订版本 | 区分原始 V1 和后续修订 |
| 4:324 等 | Figma 内部节点编号 | 用于打开具体画板或元素 |

画板中的 01、02、03 若位于区块标题处，是区块顺序提示；位于作品占位卡片中，则是临时作品编号。它们不代表网站自动轮播的页数，也不默认作为正式内容显示。

## 坐标与布局基线

单位为设计像素 px。元素位置以网页或直接父容器左上角为原点；X 与 Y 的参考容器必须明确。Figma 画布中用于摆放画板的坐标不是网页坐标。页面和区块 Y 随自动布局、文字换行和作品数量变化。

| 项目 | 桌面 | 手机 |
| --- | --- | --- |
| 基准宽度 | 1440 | 390 |
| 页面左右边距 | 80 | 24 |
| 内容宽度 | 1280 | 342 |
| 导航高度 | 96 | 72 |
| 首页 H02 至 H09 上下内边距 | 96 | 56 |
| 品牌横幅显示框 | 1280 × 470 | 342 × 220 |
| 分类面板内边距 | 32 | 16 |
| 分类面板内部宽度 | 1216 | 310 |
| 分类面板卡片 | 4 列，每张 286，间距 24 | 2 列，每张 149，间距 12 |

桌面导航、正文和页脚已统一到左右 80 的主内容对齐线。桌面普通三列卡片宽度为 `(1280 - 2 × 32) / 3 = 405.33`，列间距 32。

后台基准宽度 1440：侧栏 232，主区宽 1208、左右内边距 48，可用内容宽 1112。编辑区两栏为 720 + 24 + 368；输入框高 48，字段内标签间距 8，字段间距 24。具体局部例外查看对应后台标注板。

## 响应式规则

| 浏览宽度 | 布局规则 | 已有样例 |
| --- | --- | --- |
| 小于 768 | 单列，左右边距 24 | 390 主画板；[320 列表样例](https://www.figma.com/design/x9YTf9CS1R6DNi9NBUxCom?node-id=38-323)内容宽 272 |
| 768 至 1199 | 两列，左右边距 32 | [768 列表样例](https://www.figma.com/design/x9YTf9CS1R6DNi9NBUxCom?node-id=38-258)内容宽 704，每列 340，间距 24 |
| 1200 及以上 | 三列，左右边距 80，内容最大宽 1280 并居中 | 1440 主画板 |

分类面板有单独的列数规则，不照搬普通作品列表。手机全部分类支持横向浏览，已补上“视觉探索”入口。

320 与 768 当前只制作了作品列表具体样例。其他页面的响应式规则已有说明，尚未逐页制作这两个宽度的完整画板，也未执行真实浏览器适配验收。

## 作品类型与图片要求

“品牌设计、包装设计、视觉探索”是当前示例分类，可由维护者调整。它们是内容分类，图片显示尺寸按使用位置决定，不按类别分别规定尺寸。

| 图片用途 | 当前设计要求 |
| --- | --- |
| 作品封面 | 统一 3:4 显示比例；裁剪封面不覆盖作品原图 |
| 桌面品牌横幅 | 1280 × 470 显示框，单独设置裁剪焦点 |
| 手机品牌横幅 | 342 × 220 显示框，使用手机裁剪焦点 |
| 详情内容图片 | 按图片原始比例完整展示，不统一强行裁成 16:9 或 2:1 |
| 合作标志 | 保留标志比例，无链接时不显示可点击样式 |

上述是布局显示尺寸，不等于强制上传的源文件像素。建议提供足够清晰的原图，上传格式、体积上限和校验规则参考需求文档，最终执行值在技术方案中确认。占位图的示例纵横比不能代替详情原图比例规则。

## 设计评审和后续开发待办

- 替换真实品牌名称、标志、首页文字、联系信息与作品素材，复查长标题、长正文和图片构图。
- 确认首页 9 个区块是否全部保留，以及默认分类和作品排序。
- 评审最终字体、颜色、留白、组件状态和动效强度；画板命名中文优先的建议尚未全面执行。
- 在开发中实现并验证连续滚动联动、减少动画设置、移动端手势及键盘访问；现有动效样例不能替代网页运行验收。
- 逐页核对 320、390、768、1440 等宽度下的换行、溢出和触控行为；当前补充样例不代表整站均已验证。
- 上传、草稿、预览、发布、下架和访问控制目前是需求与界面原型，后续需要实现真实服务及跨模块验收。
- 开发前确定技术框架、认证方式、媒体存储、备份恢复与部署方案，并按模块需求中的验收条件推进。
