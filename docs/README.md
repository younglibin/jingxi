## 版本与使用顺序

功能职责、数据校验和验收条件参考模块需求说明；页面布局、组件尺寸与视觉交互优先查看当前 Figma 原稿及同页标注。需求与视觉发生冲突时先在评审中统一，开发者不要自行覆盖功能规则。

历史补充 PDF 创建于 Figma 修订之前，文件中的“尚未写回 Figma”等状态描述仅代表当时情况。后续已在原稿补充标注并修正布局；旧 PDF 的部分高度和位置提案不等于当前实际值。当前 V1.1 说明记录了这一区别。

原始 Word 与 PDF 保持归档时内容，里面涉及“本轮仅需求说明”的阶段文字也属于历史版本。后续设计状态以 V1.1 说明为准。

## 文件维护

需求正文变化时同步更新 Markdown，并注明版本和评审结论。原始文档作为版本归档保留。设计变化应先修订 Figma，再更新交付说明中的对应规则和链接；页面高度随内容和自动布局变化，不固定抄写旧数值。

后续开发代码与上述文档共用本仓库。当前没有应用构建、运行或部署命令。
