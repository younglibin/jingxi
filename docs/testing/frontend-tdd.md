## 独立评审后的回归修复

2026-10-27 02:31 UTC，评审发现的4个重要问题及详情错误状态均在修复前运行真实组件/HTTP边界回归并观察失败：

| 问题 | RED证据 | 修复与GREEN |
| --- | --- | --- |
| 公开列表JSON缺少Content-Type，真实Spring接口可能415 | 捕获fetch实际headers，Content-Type为null而非application/json | JSON格式头与CSRF判断分离；公开browse保持无会话写入 |
| 多文件上传并发撞到Java单任务限制 | 选择两张图片后active=2；同时出现两个取消按钮 | 组件级队列串行处理多选、后续添加与重试，最大active=1；取消后迟到结果仍丢弃，待请求结束才启动下一项 |
| 保存期间的新输入可能被成功响应覆盖 | 作品标题与网站品牌输入在等待响应时仍enabled | 两类编辑器内容区使用disabled fieldset，保存成功或失败后恢复编辑；异步回归验证完整等待过程 |
| 旧列表序列在刷新和切换分类时被无限复用 | 普通挂载仍渲染stale键；分类切换不出现newer键；详情返回标记未消费 | 普通打开/刷新读取新catalog；分类切换取新catalog并将take重置12；只有普通卡片进入详情设置一次返回标记，返回恢复已保存序列；category同步URL，匹配查询条件时仍恢复详情上下文 |
| 详情503或网络错误被当作404 | 503和fetch错误均抛出NOT_FOUND_ROUTE | 服务端保留HTTP状态，仅真实404进入notFound；503/网络错误显示alert和当前详情地址的重试链接 |
